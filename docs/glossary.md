# Нэр томьёоны толь (Glossary)

> UI текст монгол, код англи хэлээр байдаг тул энэ харгалзуулалт **заавал** мөрдөгдөнө.
> Нэг ойлголтод хоёр өөр англи нэр өгөхийг хориглоно.

## 2. Ачааны төлөв (§1.5)

> Замын төлөв (`in_transit`, `arrived`) байхгүй — бүртгэл нь ачаа Монголд ирсний
> дараа хийгддэг ([`business-rules.md` BR-07](business-rules.md)).

| Монгол (UI) | Код |
|---|---|
| Бүртгэгдсэн *(= Монголд ирсэн)* | `registered` |
| Хэрэглэгчид мэдэгдсэн | `notified` |
| Төлбөр хүлээгдэж буй | `awaiting_payment` |
| Төлбөр төлөгдсөн | `paid` |
| Хүргэлтэнд гарсан | `out_for_delivery` |
| Салбараас авсан | `picked_up` |
| Амжилттай хүлээлгэн өгсөн | `delivered` |
| Буцаагдсан | `returned` |
| Хүчингүй | `cancelled` |

**Ачааны төлбөрийн байдал** (BR-14):

| Монгол (UI) | Код |

| Хэсэгчилсэн | `partial` |

**Нэхэмжлэхийн төлөв** (§2.3):

| Монгол (UI) | Код |
|---|---|
| Нээлттэй | `open` |
| Төлөгдсөн | `paid` |
| Хүчингүй | `cancelled` |

> «Хүчингүй», «Төлөгдсөн» гэсэн ижил үг ачаа, төлбөр, нэхэмжлэхэд ӨӨР утга
> агуулна — тольнуудыг хольж болохгүй (frontend-д `kind` prop-оор ялгана).

| Монгол | Код |
|---|---|
| Нэгтгэсэн нэхэмжлэх | `invoice` |
| Хуваарилалт | `allocation` |
| Хуваасан төлбөр | split payment (нэг ачаа, олон `payments` бичлэг) |
| Үлдэгдэл | `balance` |
| Хүчингүй болгох (төлбөр) | `void` |

## 3. Хүргэлтийн төлөв (§5.1)

| Монгол | Код |
|---|---|
| Хүргэлт үүссэн | `created` |
| Хүргэлтэнд гарсан | `dispatched` |
| Амжилттай хүргэгдсэн | `delivered` |
| Буцаагдсан | `returned` |
| Цуцлагдсан | `cancelled` |
| Идэвхтэй хүргэлт | `created` \| `dispatched` (BR-20a) |
| Маршрутын хуудас | route sheet — жолоочийн цаас |
| Жолооч | `driver` (`driverId` эсвэл `driverName`) |
| Хүргэлтийн дугаар | `deliveryNumber` — `DLV-YYMM-NNNNNN` |

> **Ачааны `cancelled` = «Хүчингүй», хүргэлтийн `cancelled` = «Цуцлагдсан».**
> Ижил кодыг өөр үгээр орчуулж байгаа шалтгаан: ачааг хүчингүй болгох нь
> бүртгэлийн алдааг залруулах (BR-11), хүргэлтийг цуцлах нь төлөвлөгөө өөрчлөх.
> Хоёрыг нэг үгээр нэрлэвэл ажилтан ачаагаа хүчингүй болголоо гэж эмээх болно.
> Дүрсний өнгө ч тусдаа толинд (`design-tokens.js`).

## 9. Түгээмэл алдаатай орчуулга

| ❌ Буруу | ✅ Зөв | Шалтгаан |
|---|---|---|
| `cargo` / `shipment` | `package` | Нэг ойлголтод нэг нэр |
| `client` | `customer` | |
| `user` (харилцагчийн утгаар) | `customer` | `user` = дотоод ажилтан |
| `price` (бүрхэг) | `computedPrice` / `finalPrice` | Аль нь болох нь тодорхойгүй |
| `amount` (ачаан дээр) | `finalPrice` | `amount` зөвхөн төлбөр дээр |
| `deleted` | `cancelled` / `voided` | Устгал бараг байхгүй (BR-11, BR-18) |
| `bonus` | `loyaltyPoints` | |
| `warehouse` (нүдний утгаар) | `warehouseLocation` | |
| `status` (төлбөрийн) | `paymentStatus` | `status` = ачааны төлөв |
